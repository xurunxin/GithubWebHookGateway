# 2026-06-08

## GitHub Webhook Relay 项目从零搭建

根据需求文档，完整实现了 GitHub Webhook Relay 服务。

### 技术选型
- Go + 标准库 net/http（无框架依赖）
- 纯 Go SQLite 驱动（modernc.org/sqlite，CGO_ENABLED=0）
- gorilla/websocket
- Scratch 基础镜像（镜像极小）

### 已实现功能
1. **GitHub Webhook 接收** (`POST /webhook/github`): HMAC-SHA256 签名校验、delivery_id 幂等去重、事件持久化
2. **WebSocket 服务** (`GET /ws/openclaw`): Token 鉴权、hello 握手、ping/pong 心跳、事件下发、ACK 确认
3. **Relay 核心**: 事件分发循环、指数退避重试、状态机管理（pending→delivering→acked/dead）
4. **管理 API**: /health、/status、/events、/events/{id}/retry，均支持 ADMIN_TOKEN 鉴权
5. **SQLite 存储**: WAL 模式、连接池限制（max 2）、事件/Agent/日志表 CRUD
6. **Docker 部署**: 多阶段构建、scratch 基础镜像、docker-compose

### 测试覆盖 (28 tests, all PASS)
- 签名校验：valid/invalid/missing prefix/empty secret
- 幂等去重：重复 delivery_id 不重复插入
- ACK 处理：ok/failed-retryable/failed-nonretryable
- 最大重试超限进入 dead
- 手动重试 dead 事件
- 指数退避验证
- WAL 模式确认
- 状态计数、Agent 注册/断开

### 关键设计决策
- 使用 modernc.org/sqlite（纯 Go）替代 mattn/go-sqlite3（需 CGO），使 Docker 镜像可以用 scratch，体积最小
- 数据库连接池设为 max_open=2, max_idle=1，适配低配 VPS
- 事件下发批量大小可配（默认 10）
- HTTP Body 限制 25MB
