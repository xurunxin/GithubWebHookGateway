## 2026-06-08

### Initial Project Setup
- Created full Go project structure based on VPS GitHub Webhook Relay requirements
- Module: github.com/nkit/github-webhook-relay (Go 1.26)
- Tech stack: Go net/http, gorilla/websocket, modernc.org/sqlite (pure Go, CGO_ENABLED=0)
- Git repo: https://github.com/xurunxin/GithubWebHookGateway.git

### Implemented Modules
- `internal/config`: env var based configuration with defaults
- `internal/storage`: SQLite operations (events CRUD, agents, event_logs) with WAL mode
- `internal/github`: webhook handler with HMAC-SHA256 verification, idempotent delivery_id
- `internal/relay`: core relay logic (dispatch loop, ACK handling, exponential backoff)
- `internal/websocket`: WebSocket handler with auth, heartbeat, event delivery
- `internal/admin`: health/status/events/retry API endpoints

### Docker Deploy
- Multi-stage build (golang:1.23-alpine -> scratch, CGO_ENABLED=0)
- Image: registry.nkit.top/openclaw/github-webhook-relay
- docker-compose.yml with persistent volume for SQLite

### Key Design Decisions
- Switched from mattn/go-sqlite3 to modernc.org/sqlite for CGO-free builds
- DB pool: max_open=2, max_idle=1 for low-resource VPS
- Admin API: limit capped at 500, not rejected
- Query token auth supported alongside Bearer header for admin
